# Support

This page tells you where to get help with the Feedback Pilgrim Ruby SDK.

## Read the documentation

Read [README.md](README.md) first. It shows the install, the configuration and code examples. The guides for the app and for each SDK are at [feedbackpilgrim.com/docs](https://feedbackpilgrim.com/docs).

## Ask a question

Ask questions in the [Q&A category of the discussions](https://github.com/amedina068/feedbackpilgrim/discussions/categories/q-a) of the app repository. Search the existing discussions before you start a new one. Give the SDK version, the runtime version and the code that you tried.

Do not open an issue for a question. The issues are for bugs and feature requests.

## Report a bug or ask for a feature

If the problem is in the SDK, open an issue in this repository with the bug report form or the feature request form.

If the problem is in the Feedback Pilgrim server, open an issue in the [app repository](https://github.com/amedina068/feedbackpilgrim/issues).

## Report a security problem

Do not report a security problem in an issue or a discussion. Read [SECURITY.md](SECURITY.md) and report the problem in private.

## Response time

One person maintains this project, so answers are not immediate. The maintainer reads each question, but a reply can take some days.
